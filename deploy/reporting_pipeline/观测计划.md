# 观测计划（E10 OBSERVATION_ACCEPTED 候选，至少 7 业务日）

> 分组上线（ROLLOUT_PARTIAL/FULL）不等于观测完成；观测按组独立计时，
> 每组连续 7 个业务日达标才可判 OBSERVATION_ACCEPTED。

## 1. 观测分组

- G1 小表快照组（入院/体检/会诊等小键集表）；
- G2 检验双源组（LIS 4 表：路由段+Q4 重叠边界）；
- G3 高量明细组（住院/门诊费用明细、医嘱检查：含月重扫两张漂移表）；
- G4 影像/文书组（CLOB 大正文、路径表）；
- 每组独立批准上线、独立观测计时。

## 2. 每日观测指标（按表×日）

| 指标 | 判定 |
|---|---|
| 捕获完整性 | 分片完整率 100%；缺口账本新增=0 或全部有补抽计划 |
| 质量隔离 | 隔离组均有工单；无未解释隔离 |
| 装载 | COMMIT_UNKNOWN=0；受影响键内容差异=0 |
| 对账 | 键集+内容 diff=0（条数相等不算通过） |
| 反馈 | 省端回执状态可查；DEADLINE_UNCONFIGURED 表单独列 |
| 告警 | 入队/送达分开统计；ALERT_DELIVERY_FAILED 均有处置 |
| 时效 | 有 deadline 的表按 SLA；无 deadline 只记时耗分布 |

## 3. 判定门（7 业务日）

- 连续 7 业务日：无未解释差额、无盲重放事件、无同表双写者、
  告警链路可用率达标（outbox 不积压超预算）；
- 漂移两表：月重扫至少完成 1 个纳管月的完整闭环（或显式排期欠账）；
- LIS 组：Q4-2023 边界复核结论落地，无跨段漏/重。

## 4. 观测不通过的处置

- 单表回退 enabled=false，不影响同组其他表；
- 根因归层（源/视图/适配器/质量/装载/relay），按故障隔离规则入对应
  队列；观测计时归零重算（该组）。
