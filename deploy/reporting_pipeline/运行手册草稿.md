# 运行手册草稿（R189-T1 报送管道，E10 运维交接候选）

> 状态：草稿（E08 静态审阅材料）。上线后由运维交接门（OPS_HANDOVER）
> 验收后转正。内部 run_id/哈希/审批号只留内部备注，不给业务用户。

## 1. 日常 T+1 周期

1. 调度入口调用 `scheduler_bridge.run_cycle()`（单入口；禁止绕过直接起
   DataX/脚本双写）。
2. 周期顺序：T1 优先 → 补抽/回看 → 月重扫（低优先）。
3. 每表读前检查：READ_READY 层 VERDICT（身份/引擎/变更依据/画像）；
   任一 UNKNOWN → 该表保持 DISABLED，不入本轮。
4. 周期末看 `daily-report` 六个必列分节：
   - failed_windows_and_next_retry / commit_unknown_tables /
     affected_child_groups / monthly_coverage_overdue /
     deadline_unconfigured（SLA_UNKNOWN）/ relay_delivery_state。
5. 分母口径：全 77 项 / 实际适用 / 已批准上线，三个数分开看。

## 2. 告警处置（企微公共 v2）

| 告警 | 建议动作 |
|---|---|
| EXTRACT_FAILED | 看 detail_ref 定位；受控重试仍失败→按失败窗入待补；其他表继续 |
| SOURCE_LATE | 核源新鲜度预算（不是 QUERY_SLOW）；联系源侧 |
| QUERY_SLOW | 对照该表路线画像阈值；不要套统一 3 分钟 |
| VIEW_BLOCKED | 转人工工单（用户修视图）；AI 不改源 |
| QUALITY_BLOCKED | 看隔离组工单；独立合法组已在继续 |
| RECONCILE_DIFF | red：先核受影响键集与内容，不以条数相等结案 |
| COMMIT_UNKNOWN | red：冻结该表全部写者，按 §3 处置 |
| WORKER_STALE | 独立巡检发出；核 worker 心跳与租约 |
| RESCAN_OVERDUE | 历史月欠账：查覆盖账本，排期补扫 |
| DEADLINE_UNCONFIGURED | 日报单列；催省端契约确认（A12） |
| ALERT_DELIVERY_FAILED | relay 侧问题：本地 outbox 已持久，不递归发坏 relay |
| RECOVERED | 核恢复证据后自动闭（新 revision 蓝色通知） |

- 202 = 入队 ≠ 送达：以 GET 逐目标 sent 为准；
- 401 → 通道暂停自动重试（人工核凭据/时钟），抽取不受影响；
- 429/503 → 按 Retry-After；事件重试原 ID 原字节、新秒签名。

## 3. COMMIT_UNKNOWN 处置（最高优先）

1. 状态机进入 COMMIT_UNKNOWN → 同表全部正式写任务冻结
   （`blocked_scopes` 含 same_target_table_writers）。
2. 查同事务提交凭据（operation_id / batch_id / manifest_hash /
   rows_affected）与目标内容（受影响键存在性+内容 diff）。
3. 确认已提交 → 状态 APPLIED，补记状态；
   确认回滚 → APPLY_PENDING，同幂等键恢复；
   无法判定 → 保持冻结并升级人工（禁止盲重放或切下一天写）。

## 4. 月重扫运维（EMR_DOC_ORDER_CHECK / EMR_IN_FEE_INFO_CHILD）

- 覆盖账本（表×业务月×来源）到期未扫 → RESCAN_OVERDUE；
- 发布顺序：冻结范围 → 完整捕获 → 质量 → stage 验证 → 同表写权+版本
  保护 → 获批原子替换（删发布范围键清单+插 stage 同事务）→ 回读凭据 →
  全分片闭合才闭月；
- 禁止先删后等源；双源月单源完成不得删另一源范围。

## 5. 回读对账

- 用回读类型契约：CHAR 右去填充、VARCHAR/CLOB 保留空白、Decimal 精确、
  时间精度不归一；条数相等不判完整（比键集+内容）；
- 源-ODS-目标三方延迟分开记录，不用两时点 count 差下结论。

## 6. 值守与升级

- 接近截止：SLA_AT_RISK（deadline 已配置的表）；
- deadline 未配置：SLA_UNKNOWN，不伪算；
- 值班交接看板：`reporting_ctl.py daily-report` 输出。

## 7. 禁止事项（红线）

- 禁止绕过 ApplyPort 直连目标写；
- 禁止把失败标 SKIP/成功；
- 禁止在告警/日志/报告写患者数据、原 SQL、凭据；
- 禁止同表双正式写者（切换走逐表交接，见在跑任务交接快照模板）；
- 禁止未经批准向生产 relay 发测试消息或自动注册/改订阅。
