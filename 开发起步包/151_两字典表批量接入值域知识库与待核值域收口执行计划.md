# 两字典表批量接入值域知识库与待核值域收口执行计划（151）

## 0. 背景与目标

用户 2026-08-25 指定两个"重要值域信息"来源，要求在 149 值域知识库（P1–P3 已上线隔离测试库）基础上批量接入，并合并收口 149 遗留的待核值域：

| 来源 | 定位 | 物理位置 |
|---|---|---|
| `PORTAL_SYS_DICT`（含 `_TYPE`/`_CLASS` 族） | HIS/平台侧值域字典（含国标 GB_CODE/GB_NAME 映射） | 数据中心 8.216，schema `HIS` 与 `PORTAL_USER` 各一份 |
| `EMR_FIRST_PAGE_ITEM_DICT` | JHEMR 病案首页值域字典（FIELD_NAME+ITEM_VALUE→ITEM_TEXT） | JHEMR 电子病历库（10.10.8.177） |

**目标**：字典表批量进入 `asset_column_value_domains`（证据链完整、可幂等重放），与 148 已确认 21 条种子共存互校；同时把 149 遗留的离院方式 code9、手术标志 3 两条 pending 待核值域核实收口。

**非目标**：不做通用字典系统（`dict_medical` 已有）；字典导入**永不自动 confirm**（防 2026-08-24 `COMM.DISCHARGE_DISPOSITION_DICT` 事故重演——平台字典表 ≠ 具体字段的真实值域）；不改动 126/144 既有语义；不连生产平台库写（导入先在隔离测试库验证）。

## 1. 仓库离线复核结论（2026-08-25 已完成）

### 1.1 PORTAL_SYS_DICT 族（数据中心 8.216，`08` 快照 + 资产包双确认）

| 对象 | schema | 列数 | 行数 | 关键列 |
|---|---|---|---|---|
| `PORTAL_SYS_DICT` | HIS | 18 | ~1772 | DICT_CODE/DICT_NAME/**TYPE_ID/TYPE_CODE**/ENABLE_STATE/**GB_CODE/GB_NAME**/SORT_INDEX/PY_CODE |
| `PORTAL_SYS_DICT` | PORTAL_USER | 16 | ~1211 | 同上少 PY_CODE/FILED1 |
| `PORTAL_SYS_DICT_TYPE` | PORTAL_USER | 11 | **145** | TYPE_ID/TYPE_CODE/**TYPE_NAME**/CLASS_TYPE_CODE —— 145 个字典类型的登记清单（导入盘点入口） |
| `PORTAL_SYS_DICT_CLASS` | PORTAL_USER | 10 | 11 | CLASS_TYPE_CODE/CLASS_TYPE_NAME —— 11 个顶层分类 |

- 复核判断：这是平台/EMPI 统一字典，**带国标映射**（GB_CODE/GB_NAME），价值高于普通业务字典；但 145 类×平均 N 码**不能全量导入**（注入链路按 <500 条设计），须先盘点 145 类 → 用户圈定首批。
- 双 schema（HIS/PORTAL_USER）疑似新旧/同步两份，导入前须 live 比对差异，**以 TYPE 登记所在 PORTAL_USER 为准，另一份仅作差异证据**。
- 风险预判：`COMM.DISCHARGE_DISPOSITION_DICT` 事故证明"平台字典表描述的语义 ≠ 具体业务字段真实值域"。因此本族所有导入一律 `source_type=dict_table` + `status=pending`，与既有 confirmed 冲突时置 `conflict_status=conflicted` 走人工裁决。

### 1.2 EMR_FIRST_PAGE_ITEM_DICT（JHEMR，老文档 `系统表结构\电子病历数据库.md` §176）

| 列 | 类型 | 说明 |
|---|---|---|
| FIELD_NAME | VARCHAR2(32) | 病案首页字段（联合主键） |
| ITEM_VALUE | VARCHAR2(162) | 数据库保存的值（联合主键） |
| ITEM_TEXT | VARCHAR2(40) | 页面显示的值 |
| DEFAULT_FLAG / SHOW_ORDER / INPUT_CODE / BOH_CODE | — | 缺省/排序/拼音/数据库编码 |

- 文档注："病案首页中所有地区字典内容的字典配置表"——即 JHEMR 侧病案首页每个字段一套 值→显义。
- 复核判断：这是 148 离院方式事故中"正确核对基准"（JHEMR `report.r_pat_visit` 中文名）的**字典化来源**，价值极高；可用于 ①给 JHEMR 自身字段建值域（如 r_pat_visit 存的就是 ITEM_TEXT 中文名，按物理来源分开建模——149 §9 Q6）；②给 HIS_SOURCE 对应已确认值域追加 cross_system 证据。
- 仓库无 JHEMR live 元数据快照，字段结构以老文档为准，**执行 AI 须先经 sjzc 活库核对实际字段再导入**（老文档可能陈旧）。

## 2. 导入设计（与 149 模型对齐）

### 2.1 映射规则

| 字典元素 | 值域库落点 |
|---|---|
| PORTAL 字典某 TYPE_CODE 的一个 DICT_CODE→DICT_NAME | 一条 `asset_column_value_domains`：code=DICT_CODE，meaning=DICT_NAME，note 附 TYPE_CODE/TYPE_NAME/GB_CODE/GB_NAME |
| 定位键（system/source/schema/table/column） | **由人工圈定时指定目标字段**（TYPE_NAME 语义 → 具体 table.column），无法定位的字段先不导入，登记"待定位清单" |
| status | 一律 **pending**（dict_table 来源永不自动 confirm；人工核实后才升 confirmed） |
| domain_kind | enum（编码型）；GB_CODE 可用时在 note 记国标对照，不单独建行 |
| 证据 | source_type=dict_table，source_system=DATA_CENTER，snippet_ref=`PORTAL_SYS_DICT:{TYPE_CODE}`，method 注明行数/采样 |
| EMR_FIRST_PAGE_ITEM_DICT 某 FIELD_NAME 的 ITEM_VALUE→ITEM_TEXT | JHEMR 侧：system_code=JHEMR、目标字段按 FIELD_NAME 映射（如 DISCHARGE_DISPOSITION→report.r_pat_visit 相关字段），status=pending、source_type=dict_table；**同时**对 HIS_SOURCE 既有 confirmed 同义码追加 cross_system 证据（observed_meaning=ITEM_TEXT），含义不一致自动触发 149 冲突检测 |

### 2.2 硬规则（继承 149 + 本计划新增）

1. **幂等**：复用 `value_domain_service.find_by_key + evidence_duplicate`（先查后插），重复运行收敛 0；
2. **confirmed 不可被字典覆盖**：同键已有 confirmed 且 meaning 不一致 → 不改 meaning，只置 conflicted + 列 competing meanings；
3. **规模门禁**：首批导入 ≤200 条（TYPE 圈定 ≤20 类）；超出的进"候选清单"等下批；
4. **审计**：批量导入写一条 `seed_import` 汇总审计（module=value_domain）；
5. **目标库**：先在隔离测试库 `data_asset_test` 验证（隧道 127.0.0.1:55432，凭据由 backend/.env 动态构造，不打印）；**生产平台库导入须用户另行授权**；
6. **业务源库零写入**：live 探索仅 SELECT + ROWNUM 限量，走 sjzc 受控通道。

## 3. 合并收口：149 遗留待核值域核查（本计划一并执行）

### 3.1 离院方式 code 9（MEDREC.PAT_VISIT.DISCHARGE_DISPOSITION，2025-08 仅 2 例）

```sql
-- S1 聚合分布（HIS 源端，只读）
SELECT pv.DISCHARGE_DISPOSITION, COUNT(*) AS CNT,
       MIN(pv.DISCHARGE_DATE_TIME) AS MIN_DT, MAX(pv.DISCHARGE_DATE_TIME) AS MAX_DT
FROM MEDREC.PAT_VISIT pv
WHERE pv.DISCHARGE_DISPOSITION = '9'
GROUP BY pv.DISCHARGE_DISPOSITION;

-- S2 取 2 例就诊键（输出脱敏：PATIENT_ID 仅保留前2后2位）
SELECT pv.PATIENT_ID, pv.VISIT_ID, pv.DISCHARGE_DATE_TIME, pv.DISCHARGE_DISPOSITION2
FROM MEDREC.PAT_VISIT pv
WHERE pv.DISCHARGE_DISPOSITION = '9' AND ROWNUM <= 5;

-- S3 JHEMR 对账（用 S2 的键，report.r_pat_visit 看中文名）
SELECT rpv.patient_id, rpv.visit_id, rpv.discharge_disposition
FROM report.r_pat_visit rpv
WHERE (rpv.patient_id, rpv.visit_id) IN ((:p1, :v1), (:p2, :v2));
```

### 3.2 手术急诊标志 3（MEDREC.OPERATION.OPERATION_EMER_INDICATOR，2025 泌尿科 10 台）

```sql
-- S1 全院分布
SELECT o.OPERATION_EMER_INDICATOR, COUNT(*) AS CNT
FROM MEDREC.OPERATION o
WHERE o.OPERATION_DATE_TIME >= DATE '2025-01-01' AND o.OPERATION_DATE_TIME < DATE '2026-01-01'
GROUP BY o.OPERATION_EMER_INDICATOR;

-- S2 抽 10 台明细（执行 AI 先经 sjzc 核对 OPERATION 实际列名再补 SELECT 列，
--    避免老文档列名漂移；输出脱敏同上）
SELECT o.* FROM MEDREC.OPERATION o
WHERE o.OPERATION_EMER_INDICATOR = '3'
  AND o.OPERATION_DATE_TIME >= DATE '2025-01-01' AND o.OPERATION_DATE_TIME < DATE '2026-01-01'
  AND ROWNUM <= 10;
```

### 3.3 收口动作
