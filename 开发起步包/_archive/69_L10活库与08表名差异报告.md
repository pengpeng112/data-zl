# 69 L10：活库元数据快照 vs `08` 表名差异

## 1. 结论

| 项 | 值 |
|---|---|
| 对比基线 | `08_数据中心元数据快照.json`（2026-07-02 harvest，865 表） |
| 活库侧 | `asset_metadata_column_snapshots` 最新 `ods_8_216` 快照 **id=3**（540 表） |
| 仅 08 有 | **327** 表（多为非核心 schema：BL/CRBSB/CS/HRP/JXXT/PORTAL_USER 等；L10 采集未全量覆盖全部 owner） |
| 仅活库有 | **2** 表：`HIS.提取价表信息`、`HIS.结算疾病编码空的` |
| 核心域 | **HIS/CDA/MTL/JHEMR/YDHL/SM/ODS/PACS/LIS** 与 08 基本一致；HIS 活库 275 vs 08 的 273 |
| 源库写 | **零**（仅读平台 PG + 本地 08 JSON） |

**含义**：L10 对 ODS 核心业务 owner 的采集与 08 对齐良好；缺口主要是 **08 中非主航道 schema**（门户、病理 BL、HRP 镜像、杂项字典等）未进入当次 live 快照范围，而不是核心 HIS 主表大规模丢失。

## 2. 方法

```text
脚本：backend/scripts/diff_live_snapshot_vs_08.py
对比键：upper(schema) + upper(table_name)
命令示例：
  PYTHONPATH=/app python scripts/diff_live_snapshot_vs_08.py \
    --snapshot-json /path/to/08_数据中心元数据快照.json \
    --source-code ods_8_216 \
    --out /tmp/l10_diff_live_vs_08.json
```

可选 `--use-asset-tables`：当列快照为空时回退到 `asset_tables`（本轮 live 快照可用，未依赖回退）。
