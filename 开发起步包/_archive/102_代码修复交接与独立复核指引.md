```python
# 旧：assert resp.status_code == 403
# 新：
assert resp.status_code == 200
data = resp.json()["data"]
assert data.get("_notice") is not None
assert "dry_run" in data.get("_notice", "").lower() or "关闭" in data.get("_notice", "")
```
