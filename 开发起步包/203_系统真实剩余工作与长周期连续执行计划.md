## 2. 状态码和完成定义

所有任务、报告和 JSON 状态只使用下列语义：

| 状态 | 定义 |
|---|---|
| `DONE` | 实际动作、验证、证据和权威回写全部完成 |
| `LOCAL_DONE` | 本地代码/文档和本地测试完成，尚未发布生产 |
| `READY_FOR_APPROVAL` | 输入、脚本、影响、回滚和验证齐全，只差具体批准 |
| `WAITING_INPUT` | 缺具体账号、编码、业务口径、资源或责任人 |
| `WAITING_APPROVAL` | 具体动作已备齐，但生产/写库/治理/权限/Git 未批准 |
| `BLOCKED_EXTERNAL` | 院方、DBA、厂商、网络或账号条件未满足 |
| `PARTIAL_EVIDENCE_MISSING` | 曾声明完成，但当前证据不完整或不可复核 |
| `FAILED_RECOVERABLE` | 执行失败，已有安全恢复路径且未扩大影响 |

“生成文件”“写出 SQL”“请求已发出”“本地测试通过”不得替代生产完成、人工治理终态或外部闭环。
