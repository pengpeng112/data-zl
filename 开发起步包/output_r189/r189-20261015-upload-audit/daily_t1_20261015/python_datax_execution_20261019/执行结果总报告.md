## 3. 逐项特别验收对照（启动提示词 10 条）

1. **77 项不漏不重**：77/77 唯一；双源 4 表（LIS）、未提供 1 项
   （EMR_NURSE_PLAN）单列；护理 ODS 对照源（comparison）不算双源不参与
   路由；未知不可变 READY 由 `validate_enable` 硬门禁+测试双保险。✅
2. **增量覆盖**：策略枚举含撤销（RETRACT）；仅子表变化触发父组核对
   （planner.affected_child_groups + 质量层 PENDING_PARENT）；业务时间与
   变更时间分离；keyset 拒绝非唯一键；有限回看不承诺无限历史（月重扫
   limitations 落地）。✅（逻辑层；真实源变更机制仍 UNKNOWN）
3. **类型契约**：CLOB/Unicode 字节/Decimal/时间精度在 readback_types
   编码进 hash 与 diff，均有负例测试（float 拒绝、大整数不等、CLOB 尾
   空格差异、微秒差异）。✅
4. **水位/进度分离**：capture_h/apply_cursor/delivery_cursor 三游标独立；
   缺 OPEN 缺口推水位被拒（10-03 失败继续 10-04 场景测试）。✅
5. **COMMIT_UNKNOWN**：先查同事务凭据（receipt 字段齐），状态机只允许
   对账后 APPLIED/APPLY_PENDING；PG 状态不代替 Oracle 提交证据的口径
   写入代码注释与运行手册。✅
6. **单写者/版本**：fencing 租约（旧 token 校验失败测试）；旧批不覆新
   （attempt 选择+SUPERSEDED）；hash 不当版本顺序（VersionGuard 测试）。✅
7. **键+内容核对**：reconcile 先键集后内容；条数相等键集不同的显式测试。✅
8. **DataX**：退出 0 需指标+dirty=0+读写相等才 COMPLETE；querySql 渲染
   后复核范围字面量；OracleWriter 仅 INSERT（writeMode=insert 固定）；
   正式 apply 走 ApplyPort 白名单/批准。✅
9. **五态分开**：模拟（本地测试）/隔离（data_asset_test）/试点/上线/
   观测在批次与里程碑中分开记录；deadline 未配置=SLA_UNKNOWN 日报单列。✅
10. **不虚构 PASS**：112 验收场景本轮**未逐条映射为通过**——已实现的
    行为由 173+3 测试背书；矩阵文件保持预期态，E09/E10 相关全部 NOT_RUN。✅
