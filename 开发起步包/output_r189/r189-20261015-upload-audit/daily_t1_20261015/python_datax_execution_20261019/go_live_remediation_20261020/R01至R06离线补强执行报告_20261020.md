关键行为回归（新增测试断言的语义，非类名补丁）：

1. **DAG**：历史父(HISTORICAL_REPAIR)+其 T1 子任务时子绝不先于父派发；独立 T1 不受父子约束（`test_runnable_queue_ordering`）。
2. **同表多任务**：T1/月重扫/回看/多窗共存全保留，key 形如 `表:模式:窗`（`test_same_table_multi_task`）。
3. **token 贯穿**：任务在"提交处"用仓储验围栏通过；过期接管后旧 token 续期/提交被拒（`test_lease_token_passthrough`）。
4. **版本精度**：`9007199254740992/93`（float 下相等）精确分出大小；跨表/跨实例同 ID 互不污染；未知顺序 CONFLICT（`test_exact_version_compare`、`test_version_scope_isolation`）。
5. **批准不可伪造**：PlatformApprovalVerifier 拒未登记/停用/失效三种；production_mode 拒静态集合+内存版本账+无围栏（`test_approval_cannot_be_forged`）。
6. **跳过≠成功**：熔断全跳过=WAITING_WITH_BACKLOG；run 返回 FAILED/QUARANTINED 计入失败；无任务才 NO_WORK（`test_honest_overall_status`）。
7. **午夜固定窗**：锚点=院区时区昨天 [D,D+1) 半开；naive 时钟拒绝；跨午夜新锚点即新业务日（`test_frozen_anchor_window`）。
8. **2026 接续**：历史缺口不阻塞日捕获前进、阻塞连续完成游标；日报两游标分列（`test_continuous_completion_cursor`）。
9. **覆盖年龄**：只扫当月=NO_HISTORY_VISIT；60 个月单月轮转=DEGRADED（`test_coverage_age_report`）。
10. **耐久暂存**：同目录两次打开（A 退出/B 恢复）复用完整清单；半截/取消/截断/重复块一律不得 COMPLETE（`test_durable_file_stage_store`）。
11. **DataX 假成功**：真实子进程 exit0+dirty3/缺指标/超时全部拒绝 COMPLETE；凭据占位无解析器拒绝落盘（`test_real_subprocess_datax`）。
12. **阻塞 fetch 硬取消**：5 秒阻塞被 0.5s 看门狗关连接打断（<3s 返回 FetchTimeoutReached）（`test_blocking_fetch_hard_cancel`）。
