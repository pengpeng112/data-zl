## 4. 窗口、列与禁止动作

- 窗口：源 SQL 统一 `业务时间 >= :start AND 业务时间 < :end`（半开）；不写死 SYSDATE-1；不用查询时刻 SYSTEM_TIME 当水位。锚点按表逐项核（A01 配置 verified=false 字段在 A05a 现场核后才可装载）。
- SYSTEM_TIME：仅真实 INSERT/UPDATE 的目标事务内取目标当前时间（每批一次）；目标无 DATETIME 列则不插，追溯信息在控制面。**不做**496,006 历史重打标（另批，且须从已修正 ID 最近提交时刻重核，483,188 不作精确排除名单）。
- 禁止：DML 白名单外操作（DELETE/DDL）、绕执行器直写、整月 TRUNCATE/先删后抽、伪造省端回执、生产回退内存模拟、`/tmp/e2_env` 临时凭据模式。

## 5. 单批限额与回退

- 单批行预算/字节预算按表画像另冻（初始候选 5万行/256MB，超限递归拆窗月→日→小时→keyset，不能拆记 PARKED 工单）。
- 回退：按本次插入键和旧值条件精确恢复（UPDATE 记旧值进回执 scope；INSERT 回退=按键删除本次新增），**禁止删整月**；回退保留审计与实际结果记录。
