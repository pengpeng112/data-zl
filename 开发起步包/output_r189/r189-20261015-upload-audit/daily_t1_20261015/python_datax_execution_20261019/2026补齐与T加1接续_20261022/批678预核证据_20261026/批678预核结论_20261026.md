## 二、四个决定性结论

1. **33 张视图全部无 LOB 列**（普查 lob_cols 全空）——批5 T-B05-2（源侧 CLOB 暂存缺口）**不阻塞任何一张剩余表**；MED_NOTE 是 ODS 视图族唯一 CLOB。三包全部零代码可达成。
2. **EMR_DISCHARGE_RECORD_DIAGNOSIS 源视图不存在**（ALL_OBJECTS 无 `V_EMR_DISCHARGE_RECORD_DIAGNOSIS`；ods_views_bulk 2026-10-22 亦未收录；08 快照无 DDL）→ **开工单 T-B06-1，从本波剔除**；恢复条件=源端建视图后按批5 范式预核+冻结+试点。实际可跑 **32 张**。
3. **跨族类型错配 6 张表 13 列**（批5 BED_CODE/SICKBED_NUM N→S 同类+新形态 S→N/S→D/D→S），全部**配置级列表达式可解**（v2 修订，零代码）：预写模板见 §四；其中 2 列目标 NOT NULL（AFTER_OPERA_RECORD.ANES_METHOD_CODE、OPERATION_NURSING 六列）脏值→NULL→质量隔离合法子集（批1 语义）。
4. **视图重超时 2 张**（EMR_INFOR_OPERATION / EMR_INFOR_OTHERS 窗 COUNT 60s DPY-4024 超时，批4 NURSING_ASSESSMENT 同款）→ 批8 排尾+预案：**COUNT 超时≠capture 必败**（capture 是 ORDER BY ID+ROWNUM 限量，非全窗聚合），先试 capture 带超时，失败即挂工单不连坐。

## 四、类型错配清单与预写表达式（批7 生成 v2 用；执行者先预核源值样例定 mask，脏值防御=REGEXP_LIKE 挡+ELSE NULL）

| 表.列 | 源→目标 | 目标定义 | 预写表达式 |
|---|---|---|---|
| ADMISSION_DEAD_RECORD_TF.JOB_CODE | VARCHAR2→NUMBER | NUMBER 可空 | `CASE WHEN REGEXP_LIKE("JOB_CODE",'^[0-9]+\.?[0-9]*$') THEN TO_NUMBER("JOB_CODE") ELSE NULL END AS JOB_CODE` |
| AFTER_OPERA_RECORD.ANES_METHOD_CODE | VARCHAR2→NUMBER | NUMBER **NOT NULL** | 同上 CASE+TO_NUMBER（非数字→NULL→REQUIRED 隔离合法子集） |
| HOS_PREOP_DISCUSS.PROF_TECH_CATE_CODE | NUMBER→VARCHAR2 | VARCHAR2(200) 可空 | `TO_CHAR("PROF_TECH_CATE_CODE") AS PROF_TECH_CATE_CODE` |
| HOS_PREOP_DISCUSS.PERFORM_OPERATION_DATE | DATE→VARCHAR2 | VARCHAR2(14) 可空 | `TO_CHAR("PERFORM_OPERATION_DATE",'YYYYMMDDHH24MISS') AS PERFORM_OPERATION_DATE`（14 字符紧凑格式；预核目标既有值样例确认） |
| HOS_PREOP_DISCUSS.PERFORM_ANES_CODE | NUMBER→VARCHAR2 | VARCHAR2(36) 可空 | `TO_CHAR("PERFORM_ANES_CODE") AS PERFORM_ANES_CODE` |
| INFOR_ANESTHESIA.AGE_MONTH | NUMBER→VARCHAR2 | VARCHAR2(2) 可空 | `TO_CHAR("AGE_MONTH") AS AGE_MONTH` |
| OPERATION_NURSING.{OPERATION_END_DATE,OPERATION_START_DATE,IN_ROOM_DATE,OUT_ROOM_DATE,HANDOVER_DATE,RECORD_DATE} 6列 | VARCHAR2→DATE | DATE **全 NOT NULL** | `CASE WHEN REGEXP_LIKE("<col>",'^[0-9]{4}-[0-9]{2}-[0-9]{2}([ ][0-9]{2}:[0-9]{2}:[0-9]{2})?$') THEN TO_DATE("<col>",'YYYY-MM-DD HH24:MI:SS') ELSE NULL END AS <col>`（mask 预核源值后定，可能 'YYYY/MM/DD'） |
| REFERRAL_HOS_RECORD.SURGERY_START_DATE | VARCHAR2→DATE | DATE 可空 | 同上 CASE+TO_DATE |

批5 教训（必守）：**表达式必须自带 `AS <列名>` 别名**，否则 capture 行键错位（SOURCE_UNKNOWN_ERROR，v2 试错留痕先例）。

## 五、三批分波方案（32 张可跑 + 1 工单）

分波原则：冻结件复杂度通道分离（每包生成流程同构可一次完成）+ 每包小表先通 + 父子同包父先子后 + 大表/风险表集中批8 + 三包工作量均衡（批6 11 张轻、批7 11 张中、批8 10 张重）。三包**同源 ODS**（与批2/4/5 三包不同源纪律的差异已在计划§〇 明示处理）。

| 批 | 通道特征 | 表（窗行数） | 预期冻结件 |
