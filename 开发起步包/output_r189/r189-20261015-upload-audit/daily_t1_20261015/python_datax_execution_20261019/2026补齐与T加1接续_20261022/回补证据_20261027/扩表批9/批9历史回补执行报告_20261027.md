## §2 关键工程发现与处置（本轮最重要沉淀）

1. **ODS 月窗全投影恶计划（Oracle 11g）**：管道渲染 SQL 嵌套两遍投影、外层**显式列清单**。实测同窗对照：该形态取 plan_hash=61575464、**零行窗 723s/3.28B buffer gets 纯 CPU**；仅外层改 `SELECT *` 同窗 0.7s（plan 2348726961）。渲染在管道代码=零代码红线内不可改，接受节奏（部分表族如 CONSUL/RECIPE 无此问题 30-40s/窗；受影响表族 500-700s/窗）。**首组回补 40 窗同款行为**，非本批异常。
2. **双层超时链**：RowSource 看门狗 fetch_timeout（装配默认 300s）+ 连接级 call_timeout（build_oracle_connection_factory 默认 **600s**，DPY-4024；原始形态被归类 SOURCE_UNKNOWN_ERROR）。>600s 窗必断；撞取消路径另有批7 T-B07-3 同族 SIGSEGV（本批首试 HOS_CHANGE 实证一次，整进程死）。**处置=驱动组合公开工厂参数**：`build_oracle_connection_factory(timeout_ms=1_800_000)`+`build_row_source(fetch_timeout_seconds=1800)`——参数级、零代码文件改动（同首组租约 TTL 900→7200 先例），硬取消能力保留；实测后零超时失败。
3. **逐表进程隔离**：`b9_run_all.sh`（表外层）→`b9_backfill_one.py`（一表一进程+每窗增量落盘 stats+batch_id 幂等跳过）——SIGSEGV/瞬时错误只损失当窗，重跑自动续。
4. **QUARANTINED 合法子集语义**（v2 驱动补齐）：verify QUARANTINED 的窗不跳过，直接 apply 装载合法子集（apply 状态门禁含 QUARANTINED），隔离组留 OPEN 待裁定——计划§五"NOT NULL 缺失走质量隔离合法子集+工单留账"；v1 时代 16 窗漏装由补跑轮全部补齐（BOFORE +7,876、POSTOPER/PREOP/AFTER_OPERA 各数千行）。
5. **同键双行 ContractViolation（新发现，T-B05-3 同族扩大）**：源视图重复发出**完全相同**的同键行（verify 组一致放行、apply"装载计划与暂存键集不完整或有重复"契约拒绝重复键）→ 整窗无法装载，4 窗（§5.A）。与批5 ADMISSION_RECORD（行内容异→verify 隔离）为同族不同形态。
6. **瞬时 ORA-12541 三处**（源连接开/apply 目标连接/reconcile 目标读取），单事务设计下零部分写入：reconcile 阶段被打断的 3 个 DOC 窗数据已在目标（回执在案），收尾二轮补 reconcile 全过（恢复矩阵 APPLIED→RECONCILE_AND_REPORT）。
7. **>5 万行自动分片续捕生产实证**：OUTPATIENT_RECORD 05/06 月单窗 53,804/52,106 行、DOC_ORDER_CHECK 03 月 222,280 行一次捕完（keyset 分片聚合成单 chunk，批8 教训兑现）。
