# 70 浏览器验收与缺陷修复

## 1. 验收方式

本环境无真实人眼浏览器，采用 **Nginx/SPA 静态可达 + 容器内签发 JWT 调关键 API**（不改生产密码）模拟页面依赖链路。

| 步骤 | 结果 |
|---|---|
| `GET /` SPA | 200，title「山东省第二人民医院 - 数据资产平台」 |
| `GET /login` | 200 |
| index 静态资源 | favicon + `static/js`/`css` 存在 |
| Nginx `location /api/` | 反代 `127.0.0.1:8000/api/` |
| 认证后 KPI/树/表/差异/质量 | 见 §2 修复后复测 |

## 2. 发现的缺陷与修复

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| **B1** | 首页指挥中心 KPI 空白/报错 | `GET /api/v1/dashboard/summary` **500**；PG `GROUP BY` 不接受 `coalesce(namespace, schema)` 写法 | `tables.py` schema 热度统计改为一次 `coalesce` 表达式 + 同式 `group_by` |
| **B2** | 首页「运行状态」异常 | 前端调 `/api/v1/health`，后端只挂 `/health`；经 Nginx 时 `/health` 落到 SPA HTML | `health.py` 增加 `/api/v1/health` 与 `/api/v1/health/live` 别名（保留根路径给容器探活） |
| **B3** | 健康失败拖垮整页 | `Promise.all([summary, health])` 任一失败整页失败 | welcome：summary 与 health 解耦 |
| **B4** | 表目录/差异分页可能不刷新 | `el-pagination` 用 `@change`（版本兼容不稳） | 改为 `@current-change` + `@size-change` |
| **B5** | 目录树搜表名整支消失 | filter 未对父节点在子命中时返回 true | `filterTreeNode` 递归子节点 |
