## 1. 总原则（红线，所有通道适用）

1. **只读默认**：业务源库只允许 `SELECT` / 只读 CTE。DML/DDL 必须逐例审批并走 `asset_action_executors` 白名单通道，不得以"用户授权"为由改用直连写脚本。
2. **口令不落盘**：从服务器受控凭据文件读取（§3.2）；禁止写入命令行参数、代码、文档、git、日志。打印凭据文件内容属违规，`ls` 看清单即可。
3. **脱敏**：患者姓名/身份证/电话/地址进 AI、日志、报告前必须脱敏。
4. **大表**：`HIS.LAB_RESULT` 约 1 亿行——定向查询必须 `TEST_NO` 等业务键限定，禁全表扫；批量普查超过 1000 万行的表只采元数据。
5. **时间窗与通道分工**：以 `AGENTS.md`「安全红线与查询通道」为准（批量探查夜间执行并设超时；用户写明系统与目的的白天定向查询可限量直走受控连接器，`ods_8_216` 数据仓库按任务范围直接核查并留脱敏回执；通道①草稿人工审批仅属 `/api/v1/ai` 留痕流程）。
6. 网络抖动（Oracle 报 `DPY-4011`）是常态：连接加 `expire_time`、失败重试，偶发瞬断不代表库故障。

## 3. 通道 A：8.83 平台容器受控连接器（只读首选）

**模式**：本机 ssh 到 8.83 → `docker exec` 进 `data-asset-api` 容器 → 用容器内 python + 驱动连目标库。容器内已装 `oracledb 4.0.1`（thick 客户端在 `/opt/oracle`）、`psycopg2/psycopg3`、`PyMySQL`、`pyodbc`、`SQLAlchemy`。

### 3.1 执行骨架

```bash
ssh data-asset-83   # 用 §2 的 config_ai 别名
docker exec data-asset-api python /tmp/你的脚本.py        # 或
docker exec -i data-asset-api python - < 本地脚本.py
```

### 3.2 凭据读取约定

- 目录：容器内 `/etc/data-asset/credentials/`
- 文件名即源标识：`<系统>_<库型>_<IP点换下划线>.readonly`（部分早期源无 `.readonly` 后缀，如 `his_source_10_10_10_15`、`ods_8_216`、`hos_ods_10_10_10_5`）
- **格式：第一行 `user:password`**，权限 600
- 正确读法（不回显）：

```python
user, pwd = open('/etc/data-asset/credentials/ods_8_216').readline().strip().split(':', 1)
```

- `ls` 该目录 = 当前可用源清单（含当日新增）；`.bak*` 是历史备份不要用；`*.write` 是平台内部同步写账号，**外部工具不得使用**。
- IP 地址可直接从文件名反推（`10_10_10_15` → `10.10.10.15`）。

### 3.3 各库型连接样例（容器内）

**Oracle（注意 thick 模式，旧源库必须）**：

```python
import oracledb
oracledb.init_oracle_client(lib_dir='/opt/oracle')   # 容器内路径；8.53 上是 /opt/oracle/instantclient_21
user, pwd = open('/etc/data-asset/credentials/his_source_10_10_10_15').readline().strip().split(':', 1)
conn = oracledb.connect(user=user, password=pwd, dsn='10.10.10.15:1521/orcl', expire_time=2)
cur = conn.cursor()
cur.execute("SELECT ... FROM HIS.PAT_VISIT WHERE ROWNUM <= 100")   # 旧版不支持 FETCH FIRST，用 ROWNUM
```

**PostgreSQL（养成只读事务习惯）**：

```python
import psycopg2
conn = psycopg2.connect(host='10.10.10.88', port=5432, dbname='dialysis', user=user, password=pwd)
conn.set_session(readonly=True, autocommit=True)
```

**MySQL / SQLServer**：`PyMySQL` / `pyodbc`（SQLServer 连接串加 `appname='data-asset-readonly'` 便于源端识别）。

### 3.4 复用平台连接器（推荐给正式项目）

仓库 `backend/app/services/db_connectors.py` 提供带护栏的现成适配器：`OracleConnector`（内建 8.53 SSH 跳板选项）、`PostgresConnector`、`MysqlConnector`、`SqlServerConnector`、`VastbaseConnector`。统一接口 `execute_readonly(sql, params, max_rows)`，内含：只读 SQL 校验（单语句、禁注释、禁锁）、大表名单拦截、超时、行数上限+1 探针行。`DB_CONNECTOR_MAP`（db_connectors.py）是登记新库型的扩展点。

### 3.5 已知坑（写 SQL 前看一眼）

- Oracle 旧版：`ROWNUM <= N`，不用 `FETCH FIRST`；`oracledb` 必须 thick。
- PG `timestamptz` 输出带时区后缀（`2025-01-01 08:27:09.892+08`），按字符串解析时先剥时区再走掩码。
- `EXAM_REPORT` 无 `PATIENT_ID`，须经 `EXAM_NO` 关联 `EXAM_MASTER`；HIS 主键 `PATIENT_ID+VISIT_ID`（住院）/ `OUTPATIENT_NUM`（门诊）；检验 `TEST_NO`、检查 `EXAM_NO`。
- 更多数据坑见 `02_开发环境与资产总索引.md` §5。

## 4. 通道 B：平台 AI 只读 API（需留痕/审批时）

入口：`http://10.10.8.83/api/v1/ai`（nginx:80 → uvicorn:8000，容器 data-asset-api）。五步链：

1. `POST /api/v1/ai/sessions` 建会话
2. `GET /api/v1/ai/system-context` 取该系统元数据 + confirmed 值域 + 陷阱
3. `sql-risk-scan` 扫 SQL
4. `propose-sql` 提交草稿
5. **人工批准后** `drafts/{id}/execute` 执行

适合需要审计留痕、或要复用平台已登记值域/关系配方的场景。平台不可用时才回退通道 A 直查。

- **镜像库**：部分系统在 8.83 有 PG 镜像（如血透 `8.83:17432`，经 `/tmp` socket 连接），**只读事务**使用（`PGOPTIONS='-c default_transaction_read_only=on'`），禁止向镜像 CREATE 任何对象。
