2026-07-14 已对无纸化病案管理系统 `10.10.10.93:1521/orcl` 完成活库只读探查，并与 `系统表结构/无纸化表结构_AI分析版.md` 对照。

## 4. 核心业务关系

```text
TMRDDE（病案基本信息）
  ↑ FBIHID + FBINCU
T_MSS_MAIN（采集/归档主表）
  ├─ FMAINID → T_MSS_SCANRECORD（图片明细）
  ├─ FMAINID → T_MSS_SCANRECORDHISTORY（召回历史，当前主表不可反查）
  ├─ FMAINID → T_MSS_APPRECALL（召回申请）
  └─ 病案号/住院号/住院次数 → 质控、借阅、打印和日志主题

T_MSS_PRINTLISTQUEUE
  └─ FID ← T_MSS_PRINTQUEUEDETAIL.FPRINTLISTQUEUEID

T_MSS_COLLECTMETHOD
  └─ MID ← T_MSS_COLLECTLIST.MID

T_MSS_CATGROUP
  └─ FCATGROUPID ← T_MSS_GROUPLIST.FCATGROUPID
```

## 5. 视图关系种子

21 个视图共解析出 50 条基础表依赖，全部视图均至少识别到一个 CDMS 表。重点包括：

- `FILEPATHVIEW`：`T_MSS_MAIN`、`T_MSS_SCANRECORD`、`T_MSS_CATEGORY`、`T_MSS_SHAREPATH`。
- `HUAJIAN_V_T_BASIC`：`TMRDDE`、`TOFFIM`、`T_MSS_MAIN`、`T_MSS_SCANRECORD`。
- `RPA_COLLECTPATIENT`：`TMRDDE`、`T_MSS_ITFVIEW`、打印队列主表和明细表。
- `HUAJIAN_V_T_PRINTMUL`：打印套餐主表与明细表。
- `LOGINRECORD`：人员字典与科室字典。

这些依赖来自真实视图 SQL，可作为静态关系种子；若视图中存在 JOIN 条件，后续应进一步解析列级连接键。
