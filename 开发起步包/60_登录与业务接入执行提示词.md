## 六、关键技术决策（复核已定，不要再纠结）

1. **Access Token = JWT**：payload `sub/username/user_identifier/roles/exp/iat/jti`，TTL 15 分钟，RS256 生产 / HS256 开发。
2. **Refresh Token = opaque 随机串**：`secrets.token_urlsafe(48)` → sha256 存 `asset_auth_sessions`，HttpOnly Cookie，TTL 8 小时，轮换+撤销。
3. **中间件共存**：Bearer Token 先尝试 JWT 解码（成功填 request.state 跳过 ApiKey），失败回退 ApiKey 查库。机器 Token（ApiKey）和人类登录（JWT）共用一条中间件。
4. **Cookie 属性**：`HttpOnly; Secure(生产); SameSite=Lax; Path=/api/v1/auth; Max-Age=8h`。CSRF：`/auth/refresh`+`/auth/logout` 校验 `X-Requested-With` 头或 Origin 白名单。
5. **首位管理员**：新建 `create_platform_admin.py` 管人类账号（Argon2id + 一次性密码 + must_change_password），内部调 `create_admin_token.create_token()` 签发部署 Token；`getpass` 输入、幂等（重复执行报错，`--force` 才重置）。
6. **不引入 Redis**，不引入 LDAP/OIDC（二期再说）。
