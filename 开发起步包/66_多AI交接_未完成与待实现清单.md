## 4. 环境与坑（高代价）

| 主题 | 事实 |
|---|---|
| 本机 Windows | **不能直连** Oracle 业务库；经 8.83 或跳板 |
| 跳板 | `10.10.8.53:40022`；8.83→跳板可能 **无密钥 Permission denied** |
| ODS 账号 | DB 侧有写特权；平台必须 `validate_readonly_sql` |
| HIS 人员 | `COMM.SYS_EMPLOYEE` **不存在**；用 `FXHIS.SYS_EMPLOYEE` |
| Oracle thick | Client **≥19.1**；容器 `/opt/oracle`，默认链曾错指 11.2 |
| 大表 | `HIS.LAB_RESULT` 等禁全扫 |
| 测试 | `APP_TEST_DB_URL` 必须含 `test`；可用 8.83 库 `data_asset_test` + SSH 隧道 |
| 前端 | **仅 pnpm** |
| 同步到 8.83 | `deploy/scripts/sync_local_to_server.py`（需 `APP_SSH_PASSWORD` 等 env，**勿把密码写进仓库**） |
| 临时脚本 | `backend/scripts/_ro_*.py` 等 **gitignore**，勿提交 |
