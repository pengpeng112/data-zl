## 接手顺序

1. 根目录 `AGENTS.md`：安全红线、代码约束、文档维护规则。
2. 本文件：定位当前文档、资产包和归档历史。
3. `55_系统未完成事项统一执行计划.md`：唯一未完成事项执行入口。
4. 按任务读取下表指定的权威口径、证据或模块计划。

## 状态定义

| 状态 | 含义 | 使用规则 |
|---|---|---|
| 已完成 | 成果、代码或验证已达到当前验收口径 | 可直接引用；除非输入数据或用户口径变化，不重复执行 |

| 当前 | 当前规则、口径或模块计划 | 可继续维护，优先引用 |

| 归档 | 已被替代的计划或交接 | 仅历史追溯 |

## 目录维护协议

1. 会话开始：用 Glob 比对 `开发起步包/*` 与本文件；发现孤儿文件先登记或归档，再处理任务。
2. 新增文档：先确定当前最大编号加一；首行写 `> 类别` 和状态；立即登记本文件；再写正文。
3. 状态变更：在本文件对应行更新状态、用途、日期和依据；同步修改文档首行状态横幅。
4. 文档替代：先将有效结论合并到当前文档，再连同配套 `_结果.json` 移入 `_archive/`；记录原因，不删除。
5. 不在文档中记录密码、Token 或连接串。仅记录环境变量名、密钥引用和脱敏网络信息。
