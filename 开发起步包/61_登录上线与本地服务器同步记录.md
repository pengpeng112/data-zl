## 3. 本地 ↔ 服务器同步方式

脚本：`deploy/scripts/sync_local_to_server.py`

```powershell
# 1) 前端构建
cd frontend
pnpm run build

# 2) 同步（凭据用环境变量，勿写入 Git）
$env:APP_SSH_PASSWORD = "<ssh密码>"
cd ..\backend
.\.venv\Scripts\python.exe ..\deploy\scripts\sync_local_to_server.py
```

行为：
1. 打包本地 `backend/`（排除 venv/缓存/临时脚本）
2. 上传并 `docker cp` 到容器 `/app`
3. 离线安装登录依赖 wheel（若服务器已有 wheels_login）
4. 上传 `frontend/dist` 到 `/opt/data-asset/frontend-dist` 并 reload Nginx
5. 重启容器，健康检查，写入 `/opt/data-asset/LAST_SYNC_STAMP`
