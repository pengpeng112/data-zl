```bash
  /opt/data-asset/frontend-dist/current/static/js/AdvancedRelationGraph-D11-RyVv.js

```

### S3：确认用户访问的是对的地址

用户可能访问了 `http://10.10.8.83` 之外的地址（如经过其他代理）。让用户在浏览器地址栏确认 URL，F12 → Network → 看实际请求的 JS 文件名。

### S4：浏览器 Service Worker / 强缓存

- F12 → Application → Service Workers → 取消注册
- F12 → Application → Cache Storage → 清除
- F12 → Network → 勾选 "Disable cache" → 刷新
- 或者用无痕模式访问

### S5：确认图谱引擎是 G6 还是 SVG

graph/index.vue line 43：`graphEngine === 'g6' ? AdvancedRelationGraph : RelationGraph`
- 默认 `graphEngine = "g6"`（line 176）
- 如果 G6 渲染失败会回退 SVG（`policy.shouldUseSvg`，line 299）
- **两个组件都改了 force 布局**，但效果不同：
  - G6 force：Canvas 渲染，有物理动画效果
  - SVG buildForce：静态计算 220 次迭代，无动画

如果用户看到的是 SVG 版，力导向效果是静态的（节点位置算好后固定），不会有"弹簧晃动"。如果想要 Neo4j 式的交互拖拽+动态调整，需要确保用 G6 引擎。

### S6：如果布局效果不理想，调参方向

**G6 force**（AdvancedRelationGraph.vue `layoutOptions()`）：
- 节点太挤 → 增大 `nodeStrength`（如 -200）
- 节点太散 → 减小 `nodeStrength`（如 -80）或增大中心引力
- 边太长/太短 → 调 `linkDistance`

**SVG buildForce**（RelationGraph.vue `buildForce()`）：
- 排斥力常数 `6500`（增大=更散，减小=更紧凑）
- 弹簧距离 `linkDist = 180`（增大=边更长）
- 迭代次数 `220`（增多=更收敛但更慢）
- 中心引力 `0.008`（增大=更聚拢）
