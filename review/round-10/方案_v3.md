## 1.5 两层治理与三态判定（前提）

- **三态以 `git ls-files` + `git check-ignore -v` 联合判定，禁止从目录名推断**。已知锚点：`drivers/*.jar`、`取数/START_HERE.md`、`取数/_query_templates/`（豁免规则）=跟踪；根 `_tmp_*`、`*.log`、`/取数/*` 其余=忽略；两个 `*.tar.gz`、frontend 审查 raw/err=**未跟踪**（`/*.tar` 规则不匹配 `.tar.gz`）。
- 跟踪面移动用 `git mv`；忽略/未跟踪面用普通 `mv` + 迁移清单（旧路径→新路径→数量→大小→前后双 SHA-256）+ 事后核对。**取数整理是本机工作区整理，不产生 Git 协作面，不承诺 Git 级回滚。**
- **回滚细则（R12）**：目标已存在→停止并报告（禁止覆盖）；逐项记录执行状态；对"内容修改"（README 头等）记录修改前全文备份路径；迁移后发现新文件写入目标区→停止自动回滚转人工；恢复顺序=先内容后位置。

### 3.4 agent 快速获取
1. **根 INDEX.md（≤60 行，入库）**："想做 X→读 Y"路由；文首声明"本文件是路由缓存非目录权威，登记与状态以 README/55 为准"；附目录守护短表；附录含 §3.6 产生规则摘要。
2. **AGENTS.md 净增 1 行（R27）**："会话第一步：先读 INDEX.md，再按需分段读 README/55"——不改其余正文。
3. **repo_manifest.json（本地缓存，不入库）**：键=相对路径；字段白名单+**统一脱敏规则**（标题/docstring/参数含身份或患者值→以受控引用或掩码代替）；**契约四要素（R15）**：状态优先级 55>README 分组>正文类别行；过期判据=任一源文件 mtime 晚于 manifest；生成命令含输入范围与输出路径（tools/.cache/）；"现行查询"路由平台权威接口（不靠文件名推断）。工具 `tools/build_repo_manifest.py`。
4. **有效性演练（R10）**：固定 5 个代表任务（找现行查询/最新执行报告/当前待办/脚本用途/离线资产，给定输入与标准答案），统计命中正确性、**读取字节量**（对照直读 README 全文的基线）、是否误入历史计划；"上下文显著减量"为实测目标，不设文件数硬门槛。

1. 任务认领：执行前在 55/任务卡登记"本批目录范围+负责人+**认领有效期**"；完成或中断即释放并交接（R18）。

7. **开工门禁**：当前工作区约 170 条改动且 186 观察窗——P0 仅盘点；P2 起前置=保护清单锁定+与并行会话协调窗口。
